# 作品集三轮优化

目标是让访客在首页知道我交付了什么，在项目页看到一次失败如何定位，在自己的电脑上复现结果。文章继续记录实现过程和技术取舍。

| 轮次 | 目标 | 交付与验收 |
| --- | --- | --- |
| 第一轮 | 缩短作品体验路径 | 从首页进入 E102 回放，切换产品版本、错标版本和证据丢失，查看原文及第一个失败环节。网页数据由 Python 生成，终端执行同一脚本，发布前检查两端一致。 |
| 第二轮 | 留下一次可讨论的检索改进 | 保留口语改写漏检，比较词项基线与字段别名规则。逐条保存预期和实际证据，检查错误码、版本及空结果，记录规则的新边界。 |
| 第三轮 | 补齐两个可运行交付 | 知识库提供本地查询接口，覆盖原文、证据引用、无依据与超时回落。归因页展示合成数据的退款对账，复现统计口径偏差和只读拒绝。 |

GitHub Pages 提供浏览器回放和下载。本地服务支持从环境配置模型，替身调用与真实模型运行结果分别记录。项目页标注已复现的范围，线上数据和性能需要另行实测。
