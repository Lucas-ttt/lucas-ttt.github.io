## 项目案例

### 企业技术支持知识库 | 带版本约束的离线知识检索原型

**当前状态：离线原型已验证。** 使用三份自编排障资料，核心运行无需密钥或外部服务。

- **实现链路：** 用 Python 完成 UTF-8 文件读取、文本规范化、按段切片与内存词项索引，保留产品版本、错误码、证据 ID 及来源；按版本过滤后匹配，输出实际命中原文。
- **验证结果：** 同一 E102 在 v1 返回 `user_id`，在 v2 返回 `customer_id`；未收录的 v9 返回空证据和无适用依据状态。参数错误与正常空结果分别处理。
- **评测与限制：** 人工整理十条问题，三条开发、七条留出。仅把 Top-K 从 1 改为 2 后，留出样例规则验收从 5/7 到 6/7；“上传时找不到客户字段”仍未命中。结果只适用于该微型离线实验。

当前技术：Python / 内存词项索引 / 版本过滤 / 来源回查 / 离线评测。真实 LLM、Embedding、Chroma、FastAPI 与在线会话尚待接入验证。

代码与运行记录：[查看知识库原型](https://lucas-ttt.github.io/projects/support-knowledge-base/#results)。
