## 项目实践与方案

### 企业技术支持知识库 | RAG 应用 · 开发中

业务目标：面向产品手册、FAQ 与排障指南，支持客服和实施人员定位答案、回查依据，减少重复查找资料。

- **检索问答设计：** 规划文档清洗、来源记录、切分、Embedding 与 Chroma 持久化检索，结合证据 Prompt 返回答案及引用；保留版本、报错编号等业务约束。
- **可靠性设计：** 规划会话隔离与上下文预算、引用 ID 核查和资料不足反馈；区分检索故障与生成故障，在检索成功、生成超时时回退展示原文。
- **评估设计：** 以固定问题集检查检索命中、引用支持、回答质量及分阶段耗时，围绕失败案例记录定位、修改与复测过程。
- **当前进展：** 演示资料读取与分段已运行验证；完整检索问答、会话和异常处理链路待实现与验收。

技术路线（规划）：Python / FastAPI / LLM API / Chroma / SQLite。

### 归因分析系统 | Hermes Agent · 方案设计

业务目标：面向技术支持故障，串联线索补全、证据检索、原因假设、核验步骤和归因报告；拟基于 Hermes Agent 构建，尚未开始开发。

- **任务流程：** 规划补全版本与报错信息、检索依据并整理候选原因；为假设给出核验步骤，保留未确定项，经人工确认后保存归因报告。
- **工具与 Skill：** 拟通过 MCP 接入知识检索、案例查询与归因记录工具；将排障步骤、适用条件、停止条件与输出格式整理为可加载的任务 Skill。
- **执行控制：** 规划工具参数校验、写入确认、幂等处理和状态记录，设置最大步骤及超时；失败时保留已完成步骤和待处理事项，支持人工接续。
- **效果验证：** 拟记录任务完成情况、工具调用结果、人工介入点与耗时，验证缺少信息、无检索证据、重复提交及工具超时等场景。

技术路线（规划）：Hermes Agent / Python / MCP / Tool Calling / Skills / SQLite。
