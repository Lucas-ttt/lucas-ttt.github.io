## 项目案例

### 归因分析系统 | 电商经营分析 Agent

基于电商分析参考代码梳理自然语言提问、NL2SQL 取数、多维指标拆解与 HTML 报告链路，形成架构分析与改造方案。

- **业务与架构：** 梳理 insight-agent 分析任务、data-agent 自然语言取数、auth 认证与 dbmock 演示数仓的职责，明确查询结果、中间数据和报告的对应关系。
- **两项改造设计：** 围绕退款时间、金额单位与统计分母设计口径核查；针对 SQL 纠错后直接执行的路径，提出复验、只读账号与查询范围约束。
- **验证方法：** 以固定经营问题和参考查询核对取数、计算与报告数字，保存失败样例；区分维度变化贡献与因果假设。以上为参考架构分析与设计范围。

技术路线（参考架构）：Python / FastAPI / deepagents / LangGraph / NL2SQL / MySQL。

### 企业技术支持知识库 | 知识服务 RAG

面向产品手册、FAQ 与排障指南，设计帮助客服与实施人员定位答案、回查依据的知识问答流程。

- **文档处理实践：** 演示资料的 UTF-8 读取、按空行分段与片段计数已运行验证，为文档来源与片段元数据设计建立基础。
- **检索问答方案：** 设计切分、Embedding、Chroma 检索与证据 Prompt 的处理链路，保留版本、报错编号及引用来源；完整问答链路属于方案范围。
- **可靠性设计：** 规划会话隔离、上下文预算、引用核查与资料不足反馈；生成超时时返回原文，使用固定问题集分别核查检索与回答质量。

技术路线（方案）：Python / FastAPI / LLM API / Chroma / SQLite。
